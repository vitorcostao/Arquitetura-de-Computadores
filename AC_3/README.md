# 📚 Arquitetura de Computadores III

Bem-vindo ao repositório da disciplina de **Arquitetura de Computadores III**! Este repositório reúne os materiais da disciplina, organizados para facilitar os estudos e acompanhar o conteúdo apresentado ao longo do semestre.

## 🚀 Estrutura do Repositório

O conteúdo está dividido em três seções principais.

### 1. Conteúdo Teórico 📖

Nesta pasta você encontrará os slides, anotações e materiais complementares utilizados durante as aulas.

| Conteúdo | Descrição |
|----------|-----------|
| `02-memoria-primaria-secundaria.pdf` | Memória primária e secundária, organização e hierarquia de memória. |
| `03-memoria-cache.pdf` | Funcionamento da memória cache, mapeamento, políticas de substituição e desempenho. |
| `04-memoria-virtual-e-secundaria.pdf` | Memória virtual, paginação, segmentação e gerenciamento de memória. |
| `05-pipeline-escalar.pdf` | Pipeline escalar, estágios de execução e tratamento de hazards. |
| `06-pipeline-superescalar.pdf` | Arquiteturas superescalares e paralelismo em nível de instrução. |
| `07-multithread-multicore.pdf` | Processadores multithread e multicore, modelos de paralelismo. |
| `08-manycore-noc.pdf` | Arquiteturas manycore e Redes em Chip (NoC). |
| `09-arquiteturas-paralelas.pdf` | Conceitos e modelos de arquiteturas paralelas. |
| `10-arquiteturas-especificas.pdf` | Arquiteturas especializadas e aceleradores computacionais. |
| `12-memoria-virtual-paginacao.pdf` | Paginação, tradução de endereços e TLB. |
| `Complementar_Multithreading_*.pdf` | Material complementar sobre multithreading. |
| `Complementar_NoC.pdf` | Material complementar sobre Network-on-Chip (NoC). |

- Resoluções comentadas;
- Questões de revisão;
- Exercícios complementares, quando disponíveis.

### 3. Trabalhos 💻

Esta pasta será destinada aos trabalhos desenvolvidos ao longo da disciplina.

Os enunciados, materiais de apoio e demais arquivos serão adicionados conforme os trabalhos forem sendo propostos durante o semestre.

## 🎯 Objetivo

Este repositório tem como objetivo centralizar todo o material da disciplina de **Arquitetura de Computadores III**, facilitando a organização dos estudos e servindo como referência para consultas, resolução de exercícios e desenvolvimento dos trabalhos.
